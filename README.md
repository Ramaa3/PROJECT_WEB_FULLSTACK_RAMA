# NucleoMonitor React

Versi React/Vite dengan empat halaman asli NucleoMonitor dipertahankan di `public/pages/` agar desain Tailwind dan struktur halaman aslinya tidak diubah.

## Menjalankan

1. Ekstrak ZIP.
2. Buka folder `NucleoMonitor-React` di VS Code (folder yang berisi `package.json`).
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka URL yang muncul di terminal, biasanya `http://localhost:5173/`.

Navigasi tab React di bagian atas dapat membuka Dashboard, Data Fasilitas, Pemantauan, dan Laporan. Halaman HTML asli tetap tersedia di `public/pages/`.
