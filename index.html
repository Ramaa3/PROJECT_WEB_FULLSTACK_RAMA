Tentang NucleoMonitor

Prototype ini dibuat sebagai media pembelajaran pengembangan web untuk menyajikan informasi fasilitas, pemantauan lingkungan, dan laporan secara terstruktur. Sistem ini tidak digunakan untuk mengendalikan fasilitas nyata.
